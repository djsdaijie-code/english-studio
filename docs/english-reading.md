# 英文精读 v2.2.0

## 使用

1. 在首页“快速开始”或“学习内容”中打开“英文精读”。
2. 点击“粘贴英文文章”，填写标题并粘贴网页正文，来源网址可选。
3. 点击“整理并预览”。程序合并网页折行，清理多余空格与控制字符，保留自然段；正文仍可修改。
4. 确认后点击“开始精读”。程序使用已有拆句服务生成句子。
5. 左侧阅读英文原句，右侧查看中文意思与重点表达；可点击小喇叭朗读，选中或双击单词加入单词本。
6. 点击上一句、下一句，或按左右方向键与 Enter 翻页。Space 控制当前句朗读；末句点击“完成精读”。
7. 阅读位置自动保存，下次从精读列表继续。顶部“打字练习”打开原有练习进度。

## 数据与服务

- 正文统一保存在现有 articles / article_sections 表，整篇一个 section；重复内容复用同一文章，已软删除内容可恢复。
- 句子由已有 SentenceService 生成；翻译复用 sentence_translations 缓存与 DeepSeek 协议。
- 阅读书签保存为现有 settings 表中的 reading.article.<id> JSON，包含正文哈希、句子位置、句子总数、完成状态和可选来源网址；正文改变后安全重置阅读位置。
- 打字进度和阅读书签独立。精读不生成 WPM、practice_sessions 或句子打字 attempt。
- 只有当前句需要翻译时才请求服务，缓存命中无需 Provider；网络等待暂停学习计时，阅读获得讲解后使用原 90 秒空闲规则。
- 旧回调只写缓存，不覆盖新句子的讲解；关闭程序时取消精读请求，把未完成缓存改为可重试状态。
- 没有 DeepSeek Key 时显示未配置提示，已有缓存可离线阅读。朗读复用现有 MiniMax 与音频缓存。
- schema 保持 13，没有新增迁移或数据库表。
