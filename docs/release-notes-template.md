## Installation

- Run the Windows setup program, or extract the portable ZIP and run `EnglishStudio.exe`.
- Windows may show a SmartScreen warning for an unsigned build. Verify the published SHA-256 before proceeding.

## Privacy and data

- User data stays in `%LOCALAPPDATA%\EnglishStudio`; legacy data is retained during migration.
- Optional online services require user-provided credentials.

## Known limitations

- Azure pronunciation scoring is Beta until real-resource validation is completed.
