# 币圈与区块链英语：MVP 课程计划

## 定位

- 课程 ID：`crypto-blockchain-english`
- 版本：`0.1.0`
- 规范版本：`1.0`
- 状态：`draft`
- 规模：1 个 Level、2 个 Unit、14 个 Day、40 条句子
- 核心任务：读懂并准确输入钱包、交易、DeFi、链上指标和风险场景中的高频英语

本课程只教授语言和基础概念，不提供币种推荐、价格预测、收益承诺或投资建议。内容避免绑定交易所临时界面、协议短期参数、实时收益率和特定代币价格。

## 教学结构

| Unit | 主题 | 新句数 | 教学目标 |
|---|---|---:|---|
| 1 | 钱包、交易与链上安全 | 20 | 区分钱包密钥、转账状态、交易订单、授权与钓鱼风险 |
| 2 | DeFi、市场指标与风险 | 20 | 理解 DeFi、TVL、估值指标、质押、跨链和合约风险 |

每个 Unit 使用 7 Day 节奏：

1. Day 1–4：每天学习 5 条新内容，严格打字为必做。
2. Day 5：复用已学句子组成真实操作或阅读场景。
3. Day 6：比较容易混淆的术语，不增加新句。
4. Day 7：复习全部 20 条句子，提供可选 FSRS 课程复习。

## 能力边界

- 课程只配置 `typing` 与可选 `fsrs` 活动。
- 不配置朗读、听写、跟读、`listening`、`dictation` 或 `speaking`。
- 40 个 Sentence 的 `audio_hint` 均为 `null`。
- 中文翻译、核心词和句型仍随逐句打字界面提供。
- 课程正文只从 `CourseRepository` 加载，不写入文章表。

## 核心术语

Unit 1：crypto wallet、public address、private key、recovery phrase、network、gas fee、pending、confirmed、transaction hash、centralized exchange、decentralized exchange、market order、limit order、liquidity、slippage、token approval、phishing。

Unit 2：DeFi、liquidity pool、liquidity provider、impermanent loss、yield、TVL、Total Value Locked、market capitalization、circulating supply、fully diluted valuation、trading volume、staking、validator、oracle、bridge、Layer 2、stablecoin、leverage、liquidation、audit。

## 版本与稳定标识

- Sentence ID 使用 `crypto-s0001` 至 `crypto-s0040`。
- Item stable key 使用 `crypto-blockchain-english-sentence-0001` 至 `crypto-blockchain-english-sentence-0040`。
- Day 5–7 只引用既有 Item，不为复习创建重复 stable key。
- 正式发布后，排序、翻译和轻微措辞修正不得改变 stable key。
